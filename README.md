# SHL Smart Recommender AI Agent

An AI-powered SHL assessment recommendation system built using FastAPI and Gemini.

The system recommends SHL assessments based on hiring needs while following strict catalog-grounded recommendation rules.

---

## Features

- FastAPI backend
- Gemini-powered recommendation engine
- SHL-inspired recruiter UI
- Dark / Light mode
- Stateless multi-turn conversations
- Strict JSON responses
- Clarification handling for vague queries
- Refusal handling for unsafe/out-of-scope prompts
- Local fallback recommender for reliability
- Cleaned assignment-safe SHL catalog
